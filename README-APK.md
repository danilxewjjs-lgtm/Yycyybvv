# Как получить APK Toaster VPN (10 минут, без программирования)

1. Зарегистрируйся на github.com (бесплатно) и создай новый репозиторий.
   Название любое, например `toaster-vpn`. Поставь галочку **Private**.
2. В репозитории нажми **Add file -> Create new file**.
3. В поле имени файла впиши ровно: `.github/workflows/build.yml`
   (когда напишешь слэши, папки создадутся сами).
4. Открой файл `build.yml` из этой папки, скопируй всё содержимое и вставь в большое поле.
   Нажми **Commit changes**.
5. Открой вкладку **Actions**, слева выбери **Build Toaster VPN APK**,
   справа нажми **Run workflow**.
6. Через 15-30 минут сборка станет зелёной. Открой её и внизу, в разделе **Artifacts**,
   скачай `Toaster-VPN-apk` (это zip, внутри файл `.apk`).
7. Скинь APK на телефон и установи (разреши установку из неизвестных источников).

## Как подключить свой VPN в приложении
1. На компьютере запусти `make-client.py` (получится файл `toaster-client.json`).
2. Перекинь `toaster-client.json` на телефон.
3. В приложении: Профили -> Новый профиль -> Импорт из файла -> выбери `toaster-client.json`.
4. Включи профиль и нажми запуск.

## Если сборка упала (красная)
Открой упавший шаг, скопируй последние 30 строк текста и пришли мне. Больше всего
вероятность проблем на шаге «Собрать ядро (libbox)»: проект открытый, и его сборочные
команды со временем меняются.

использования это нормально. Если будешь раздавать APK другим людям, нужно также
